----------------------------------------------
v3.5  (16 ก.ย. 2569) — บังคับเลือก Box Out
----------------------------------------------
- แบบ "ward นำกล่องมาแลก": ช่อง "กล่องที่จ่ายไป (Box Out) *" ต้องเลือกทุกครั้ง
  (เดิมปล่อยว่างได้ = กล่องเดิมกลับ ward) ถ้าไม่เลือก จะขึ้นข้อความแนะนำให้เลือกเลขกล่องเดิม
- เลือกเลขกล่องเดิมได้แล้ว (เดิมระบบไม่ยอม) — อยู่บนสุดของรายการ
  "กล่อง X — กล่องเดิม (ไม่เปลี่ยนกล่อง)"
  · กล่องเดิมจะไปอยู่ที่ Ward ที่เลือก ถ้าเลือก Ward เป็นที่อยู่เดิม กล่องก็อยู่ที่เดิม
  · ไม่มีการสลับกล่อง
- รายการ Box Out บอกตำแหน่งปัจจุบันของแต่ละกล่อง เช่น "กล่อง 18 CPR · ห้องยา OPD (พร้อมจ่าย)"
- ช่อง Ward เลือก "ห้องยา OPD" / "ห้องยา IPD" ได้แล้ว
  และเมื่อเลือกกล่อง แอปใส่ตำแหน่งปัจจุบันให้ รวมกรณีกล่องอยู่ห้องยา
- เปลี่ยนกล่องที่นำมาเปลี่ยน → ช่อง Box Out ถูกล้าง ให้เลือกใหม่
- หน้าประวัติ: กล่องเดิมแสดงเป็น "3 (กล่องเดิม)" · สลับกล่องแสดง "1 → 18" เหมือนเดิม
- หน้าต่างบันทึกสำเร็จ: "กล่องที่จ่ายไป: กล่องเดิม → ห้องยา OPD"
- แบบ "เปลี่ยนยา / ต่ออายุกล่อง" ยังใช้ได้เหมือนเดิม (ไม่ต้องกรอก Box Out)
- แท็บวิธีใช้อัปเดตขั้นตอนแล้ว
- หมายเหตุ: รายการแบบ "ward นำกล่องมาแลก" ที่เลือกกล่องเดิม ยังนับในสถิติปัญหาและรายงานตามปกติ

เครื่องที่ยังใช้ไฟล์เก่าจะยังเห็นกล่อง 26–30 และข้อมูลไม่หาย แต่ข้อความบางจุดยังเขียน 5–25

[ใหม่] เปลี่ยนยา / ต่ออายุกล่อง โดยไม่ย้ายกล่อง
- หน้ากรอกข้อมูลมีตัวเลือกประเภทการบันทึก 2 แบบ:
  1) "ward นำกล่องมาแลก" (แบบเดิม)
  2) "เปลี่ยนยา / ต่ออายุกล่อง" — เช่นกล่องในห้องยาหมดอายุ หรือยาในกล่องใกล้หมดอายุ
- แบบที่ 2 ไม่ต้องกรอก Box Out, Ward และปัญหาที่พบ
  กรอกแค่ กล่อง, เภสัชกร, วันที่ และยาที่เปลี่ยน แล้วกด "บันทึกการเปลี่ยนยา"
- แสดง "ตำแหน่งกล่อง (ไม่เปลี่ยน)" ให้เห็นก่อนบันทึก
- หลังบันทึก: กล่องอยู่ที่เดิม · วันหมดอายุกล่องใหม่ = วันที่เปลี่ยน +3 เดือน −1 วัน (เหมือนการแลก)
  · กล่อง HAD อัปเดตยาอายุสั้นสุด · กล่อง CPR อัปเดต Lot ของยาที่เปลี่ยน (ไม่ต้องใส่จำนวน)
- หน้าต่าง "บันทึกสำเร็จ" แสดง "ตำแหน่งกล่อง: อยู่ที่เดิม"
- รายการประเภทนี้แสดงในหน้าประวัติและไฟล์ Excel (ปัญหาที่พบ = "เปลี่ยนยา/ต่ออายุกล่อง (ไม่ย้ายกล่อง)")
  แต่ไม่นับในสถิติแท็บ "ปัญหา" ของ Dashboard และไม่นับในหน้ารายงาน
- ฟอร์มจำประเภทที่เลือกไว้สำหรับรายการถัดไป

[ใหม่] แท็บ "วิธีใช้" ในแอป (ไม่ต้องใช้ PIN)

v2  (11 ก.ย. 2569) — Dashboard ใหม่
----------------------------------------------

- คาปิบาร่าเป็นแถบสรุปเรื่องด่วน: สีพื้นเปลี่ยนตามสถานการณ์ (แดง/เหลือง/เขียว)
  และปุ่มตัวเลขกดได้ (กล่องหมดอายุ, กล่อง <7 วัน, กล่อง <30 วัน, Lot ไม่ครบ, ยาหมด/<60 วัน)
- แสดงเวลาข้อมูลล่าสุด พร้อมปุ่ม "ดึงข้อมูลล่าสุด"
- แท็บกล่อง: ปุ่มกรองตามสถานะ, ช่องค้นหาเลขกล่อง/ward, เรียง "ด่วนก่อน" หรือ "เลขกล่อง",
  การ์ดเน้นจำนวนวันที่เหลือ บอกว่าอิงจากยาหรือตัวกล่อง, มือถือเป็นแถวกระชับ
- แท็บยา: รวมเป็นรายการเดียว ใช้เกณฑ์ 60 วัน (ป้าย "วางแผนเบิก"),
  เปิดมาเจอ "ต้องดูภายใน 60 วัน" ก่อน, คอมเป็นตาราง มือถือเป็นการ์ด
- แท็บตำแหน่ง: ห้องยา OPD/IPD ขึ้นก่อน, ward ว่างย่อเหลือบรรทัดเดียว,
  มือถือพับ ward ที่ไม่มีเรื่องด่วนไว้
- แท็บปัญหา: กราฟแท่งแทนกราฟวงกลม (ไม่นับ "ไม่พบ Med error"),
  แนวโน้มรายเดือน + ปุ่มแสดงเป็นตาราง, ตัวเลือกเดือนภาษาไทยใช้ได้ทุกเบราว์เซอร์
